# SpeechSpec

Speculative decoding for CosyVoice-style TTS LLMs (text → speech tokens) in vLLM.
Parallel drafters (DFlash / DSpark, trained with [vllm-project/speculators](https://github.com/vllm-project/speculators))
accelerate CosyVoice2/3 speech-token generation by **1.2–3.1x** without changing the output distribution.

## Models & datasets

| HF repo | What it is |
|---|---|
| [yuekai/cosyvoice2_llm](https://huggingface.co/yuekai/cosyvoice2_llm) | CosyVoice2 0.5B LLM (target model) |
| [yuekai/Fun-CosyVoice3-0.5B-2512-LLM-HF](https://huggingface.co/yuekai/Fun-CosyVoice3-0.5B-2512-LLM-HF) | CosyVoice3 0.5B LLM (target model) |
| yuekai/cosyvoice2_llm_dspark | CosyVoice2 DSpark drafter (3 layers, block 8) — recommended |
| yuekai/cosyvoice2_llm_dflash | CosyVoice2 DFlash drafter (5 layers, block 4) |
| yuekai/cosyvoice3_llm_dspark | CosyVoice3 DSpark drafter (3 layers, block 8) |
| [yuekai/seed_tts_cosy2](https://huggingface.co/datasets/yuekai/seed_tts_cosy2) | Seed-TTS test set with CosyVoice2 prompt speech tokens |
| yuekai/seed_tts_zh_cosy3 | Same test_zh set with CosyVoice3 (`speech_tokenizer_v3_25hz`) prompt tokens added |

All drafters are [speculators](https://github.com/vllm-project/speculators)-format checkpoints trained on
on-policy data (labels generated by the target model itself under deployment sampling parameters).

## Requirements

- **vllm-omni 0.25.1** (provides `draft_sample_method="probabilistic"` and DSpark support).
- **CosyVoice3 only**: the repetition-penalty mirror
  ([vllm-project/vllm#48932](https://github.com/vllm-project/vllm/pull/48932)) is required for the
  reported speedups. CosyVoice3 must be sampled with its official parameters
  (`top_k=15, repetition_penalty=1.1`) to avoid runaway generation, and without the mirror the
  drafter cannot see the penalty that the target applies, costing most of the acceptance.
  Until the PR is merged, install the fork and set `PYTHONPATH`:

```bash
pip install vllm-omni==0.25.1
git clone -b dspark-draft-sampling-mirrors https://github.com/yuekaizhang/vllm
export PYTHONPATH=/path/to/yuekaizhang/vllm:$PYTHONPATH
```

## Usage

`benchmark_tts.py` measures wall time, throughput, and speculative acceptance over a seed-tts style
dataset with zero-shot voice-clone prompting (`<|sos|>{text}<|task_id|>{prompt speech tokens}...`).
Only LLM token generation is benchmarked (no token2wav).

```bash
# CosyVoice2 baseline (no draft model)
python3 benchmark_tts.py \
    --target-model yuekai/cosyvoice2_llm \
    --dataset yuekai/seed_tts_cosy2 --dataset-split test_zh \
    --batch-size 1,8,16,64 --output-json cv2_baseline.json

# CosyVoice2 + DSpark drafter (recommended)
python3 benchmark_tts.py \
    --target-model yuekai/cosyvoice2_llm \
    --draft-model yuekai/cosyvoice2_llm_dspark \
    --dataset yuekai/seed_tts_cosy2 --dataset-split test_zh \
    --batch-size 1,8,16,64 --output-json cv2_dspark.json

# CosyVoice2 + DFlash drafter
python3 benchmark_tts.py \
    --target-model yuekai/cosyvoice2_llm \
    --draft-model yuekai/cosyvoice2_llm_dflash \
    --dataset yuekai/seed_tts_cosy2 --dataset-split test_zh \
    --batch-size 1,8,16,64 --output-json cv2_dflash.json

# CosyVoice3 baseline / + DSpark drafter (official sampling params; the
# repetition-penalty mirror is enabled automatically when --repetition-penalty != 1.0)
python3 benchmark_tts.py \
    --target-model yuekai/Fun-CosyVoice3-0.5B-2512-LLM-HF \
    --draft-model yuekai/cosyvoice3_llm_dspark \
    --dataset yuekai/seed_tts_zh_cosy3 --dataset-split test_zh \
    --top-k 15 --repetition-penalty 1.1 \
    --batch-size 1,8,16,64 --output-json cv3_dspark.json
```

Notes:

- The speculative method (`dflash`/`dspark`) and `num_speculative_tokens` are auto-derived from the
  draft checkpoint's `config.json`; override with `--method` / `--num-spec-tokens` if needed.
- The CosyVoice3 text prefix (`You are a helpful assistant.<|endofprompt|>`) is auto-applied when the
  target model name contains "cosyvoice3"; override with `--text-prefix`.
- The prompt speech-token column is auto-detected (`prompt_audio_*_tokens`); use `--prompt-tokens-key`
  to pick one explicitly, or `--no-prompt-tokens` for text-only prompting.
- Deploy outside the benchmark with vLLM directly:

```python
from vllm import LLM
llm = LLM(
    model="yuekai/cosyvoice2_llm",
    speculative_config={
        "model": "yuekai/cosyvoice2_llm_dspark",
        "method": "dspark",
        "num_speculative_tokens": 7,
        "draft_sample_method": "probabilistic",
        # CosyVoice3 (repetition_penalty=1.1) additionally needs:
        # "draft_apply_repetition_penalty": True,   # vllm PR #48932
    },
)
```

## Results

Full `test_zh` set (2020 voice-clone prompts), single H100, vLLM 0.25. Wall time (tok/s) and
speedup vs the no-speculation baseline; "accept len" = average tokens emitted per decoding step.

### CosyVoice2 (temperature 0.8, top_p 0.95, top_k 50)

| batch | baseline | dflash | dspark |
|---|---|---|---|
| 1 | 674.3s (674 tok/s) | 373.2s (1174 tok/s) **1.81x** | 314.5s (1406 tok/s) **2.14x** |
| 8 | 175.6s (2488 tok/s) | 87.2s (5058 tok/s) **2.01x** | 69.0s (6536 tok/s) **2.55x** |
| 16 | 125.1s (3576 tok/s) | 55.3s (7912 tok/s) **2.26x** | 43.0s (10255 tok/s) **2.91x** |
| 64 | 49.6s (8980 tok/s) | 22.9s (19363 tok/s) **2.17x** | 20.7s (21465 tok/s) **2.40x** |
| accept len | — | 2.81 | 3.26 |
